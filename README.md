# Morning and Evening

CIS 300 class site for Charles Spurgeon’s *Morning and Evening* readings.

## Pages
- `index.html`: Home (full featured pair and HTML5 video slot)
- `about.html`: About
- `week.html`: This Week (table and full bodies)
- `contact.html`: Contact (form and mailto)

## Data
- `data/today.json` and `data/this-week-full.json` hold the public-domain
  text used to write the static Home and This Week pages.
